# Functional Requirements

## FR-01 Add Student
The system shall accept a student name and create a new student record.

## FR-02 Duplicate Student Check
The system shall inform the user if the entered student name already exists.

## FR-03 Mark Attendance
The system shall allow the user to enter `P` for present or any other response for absent. The total attendance count shall increase by one.

## FR-04 View Report
The system shall display each student's name, number of present days, total attendance days and grade.

## FR-05 Search Student
The system shall search for a student by name and display attendance, attendance percentage and grade.

## FR-06 Attendance Warning
The system shall display a warning when a searched student's attendance percentage is below 75%.

## FR-07 Delete Student
The system shall delete an existing student record.

## FR-08 Calculator
The system shall support:
- Addition
- Subtraction
- Multiplication
- Division
- Exponentiation
- Modulus
- Floor division

## FR-09 Set Grade
The system shall accept a grade from 0 to 100 and store it for the selected student.

## FR-10 Grade Classification
The system shall display A, B, C, D, E or F according to the entered score.

## FR-11 Exit
The system shall terminate when the user selects option 8.
