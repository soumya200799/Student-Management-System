# Student Management System

The Student Management System is a simple Python based project designed to manage basic student information. The system allows the user to add students, manage attendance, assign grades, search for student records, delete students, view reports, and perform basic calculations. It provides us a easy 



## Overview

Teachers currently track attendance and grades by hand or in scattered spreadsheets, which makes it easy to miss students falling behind. This tool keeps one place to add students, log daily attendance, record grades, and instantly see which students are below the 75% attendance line or need academic support — with everything saved automatically between runs



## Features

* **Attendance tracking** — mark present/absent per student per session, with running totals.
* **Grading** — record a 0-100 grade per student, auto-mapped to a letter band (A-F) with a short remark.
* **Class reporting** — per-student table plus class-wide averages and a flagged list of students below 75% attendance.
* **Search \& delete** — look up or remove a single student record.
* **View Student Report -** view all the details of student.
* **Calculator**- perform basic calculations
