# Problem Statement

Teachers, especially those handling multiple small classes, commonly track attendance and grades using paper registers oy spreadsheets. This makes it slow to answer simple but important questions — "who is below 75% attendance this term?" or "what's the class average right now?" — and increases the risk of data being lost, miscounted, or forgotten between sessions.

## Scope of the Project

This project is a command-line Student Management System that lets a single teacher maintain a class roster, log daily attendance, record grades, and generate an instant class report. It is scoped as a single-user, local tool — it does not cover multi-teacher accounts, timetabling, or networked access.

## Target Users

* School or college teachers managing their own student records like attendance, grades etc. hassle free and easily 
* Students of this project itself, to track their records like attendance and grades.

## High-Level Features

1. **Student records** — add, search, and delete students.
2. **Attendance tracking** — mark present/absent per session and see running attendance percentages.
3. **Grading** — record grades on a 0-100 scale, auto-mapped to a letter grade with a short remark.
4. **Reporting** — a class-wide report showing per-student stats plus averages and a flagged "at risk" list (attendance below 75%).
