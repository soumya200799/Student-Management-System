# Project Statement

## Title
Student Management System

## Problem Statement

Educational institutions need a simple way to maintain basic student information such as student names, attendance and grades. Manual handling can make searching, updating and reporting student information inconvenient.

## Proposed Solution

The Student Management System is a menu-driven Python console application. It provides operations for adding, searching and deleting students, recording attendance, viewing reports, setting grades and performing basic calculations.

## Objectives

- Maintain a list of students.
- Record attendance for each student.
- Store a grade for each student.
- Display student reports.
- Search student records quickly.
- Delete unwanted student records.
- Provide a basic calculator.
- Demonstrate Python dictionaries, loops, conditions, input/output and arithmetic operations.

## Scope

This version is intended as a small educational/academic project. It uses in-memory storage and does not include a database, login system or graphical user interface.
